# VirusDiag — Génie logiciel et IA

Exercice de programmation orientée objet : diagnostic à partir d'un modèle
déjà entraîné. Support : cours de Génie logiciel et IA, FSSM,
Pr. Soukaina Mjahed, chapitre 5, pages 132 à 147.

Le projet suit l'organisation `data`, `core`, `pipeline`, `utils` et `app`
présentée dans le cours. Python 3.10 ou ultérieur ; aucune dépendance externe.

Projet pédagogique avec données entièrement fictives. Il ne constitue pas un
outil de diagnostic médical.
